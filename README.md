# ForkGuard

ForkGuard is a capstone project focused on improving forklift safety through embedded systems, sensing, localization, and mechanical integration.

This repository contains the code, hardware-related files, schematics, and case design files used in the development of the ForkGuard prototype.

## Project Overview

The goal of ForkGuard is to build a prototype safety system for forklifts that can monitor important operating conditions and support safer vehicle use through embedded hardware and software.

The project includes work in several areas:
- embedded firmware development
- localization and positioning
- hardware integration
- case and mechanical design
- schematic development
- component-level testing and organization
